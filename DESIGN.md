# Sistema de diseño SIFE Normativa

Esta interfaz aplica el sistema **Architectural Modernism / Neo-Editorial Corporate** facilitado para el proyecto. Se conservan su retícula, tipografía, densidad, geometría, elevaciones y semántica de componentes, con una adaptación cromática necesaria para la identidad SIFE.

## Adaptación de identidad

- El rol azul institucional del documento original se traduce a burdeos SIFE: `#651020`, `#7f1728` y `#9d2034`.
- El naranja de seguridad se conserva como acento: `#ab3500` para texto y controles accesibles; `#e84d05` queda reservado al acento visual brillante.
- El verde de validación se reserva para contenido vigente o verificado: `#127c51`.
- El lienzo, las superficies y los contornos siguen el sistema original: `#fbfbfd`, `#ffffff`, `#eff4fa` y `#e3e8ed`.

## Tipografía y escala

- Encabezados: Plus Jakarta Sans.
- Interfaz, metadatos y texto administrativo: Inter.
- Hero: `40/48 px` en escritorio y `30/38 px` en móvil.
- Encabezado de página: `32/40 px` en escritorio y `24/32 px` en móvil.
- Cuerpo: `14/22 px`; texto destacado: `16/26 px`; etiquetas: `11/14 px`.
- Métricas, cursos y fechas usan cifras tabulares.

## Componentes

- Botón normal: altura `42 px`, radio `6 px`.
- Campos: altura `40 px`, radio `6 px`, foco de tres píxeles.
- Tarjetas y paneles: radio `8 px`, contorno de un píxel y elevación ambiental mínima.
- Estados: píldoras de `22 px`; verde para vigente, ámbar para comprobar y gris para histórico.
- Modal documental: radio `12 px`, sombra de nivel 4 y fondo desenfocado.
- Espaciado: retícula principal de `8 px` con subpasos de `4 px`.

La adaptación mantiene la marca oficial SIFE y no modifica el corpus, sus estados jurídicos ni los vínculos a fuentes oficiales.
